# Public domain wallpapers

Desktop wallpapers you can use for anything. They're dedicated to the public
domain under [CC0 1.0](LICENSE), so you don't need to ask permission or give
credit.

All images are 3840x2160 PNGs.

## Styles

| Style | Count | What it looks like |
|---|---|---|
| [Aurora](wallpapers/aurora/) | 8 | Soft, glowing ribbons of colour over dark or pale skies |
| [Cosmic](wallpapers/cosmic/) | 8 | Invented nebulae, star fields and the occasional planet |
| [Flow field](wallpapers/flowfield/) | 8 | Thousands of fine lines following a smooth current, like silk or ink |
| [Geometric](wallpapers/geometric/) | 8 | Low-poly gradients, stained glass, hexagon and triangle tilings |
| [Landscape](wallpapers/landscape/) | 8 | Layered mountains, dunes, hills and coasts fading into haze |
| [Minimal](wallpapers/minimal/) | 16 | One to three flat colours and a single shape or line |
| [Tech](wallpapers/tech/) | 16 | Terminal prompts, code symbols, circuit traces and grids |
| [Topographic](wallpapers/topographic/) | 8 | Contour maps of terrain that doesn't exist |

Each style's folder has a README listing its variants.

## Why you can trust the license

A public domain dedication only means something if nobody else has a claim on
the work. To keep it that way:

- Every image was generated procedurally with original code. No outside
  photos, textures, map data or other artwork went into them.
- No fonts were used. The text in the tech wallpapers is made of letterforms
  drawn from scratch for this project, so no typeface license applies.
- No AI image generators were used.
