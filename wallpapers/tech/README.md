# Tech

Minimal wallpapers for developers: monospace lettering, terminal prompts,
grids, circuit traces and diagrams, each in one to three colours.

The lettering doesn't come from any font. It uses one original rounded
monospace letter set drawn from scratch for this project, not traced from or
measured against any existing typeface.
